    Open Actions → Backfill climb regions

    Land-monolith opsplitsen (bv. cf-l45-switzerland.json na een hele-land import): verdeel klimmen naar de juiste subregio-bundles zonder opnieuw te downloaden. Slugs met ranking-index → direct; rest via geo-fallback (startpunt → dichtstbijzijnde Climbfinder-regio, geen macro-klimgebieden). Daarna index rebuild + dedupe (kleinste dataset wint).
